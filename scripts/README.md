#Scripts

```groupAnalysis.mlx```: group-level analysis for all features\
```prePostTic_Analysis_Left.mlx```: converts sample-by-sample video annotations into discrete behavioral events for spectral LFP decomposition from the left hemisphere\
```prePostTic_Analysis_Right.mlx```: converts sample-by-sample video annotations into discrete behavioral events for spectral LFP decomposition from the right hemisphere\
```surrogateTicCoherence.mlx```: creates a surrogate marker of tic trials\
```shadedErrorBar.m```: generate continuous error bar (mean +/-sd) area around a line plot
